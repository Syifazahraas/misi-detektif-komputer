# Misi Detektif Komputer

Prototype media pembelajaran interaktif Informatika **kelas X SMA/Fase E** untuk materi **Komponen, Fungsi, dan Cara Kerja Komputer**.

Project ini diselaraskan dengan Modul Ajar, Bahan Ajar, dan LKPD Informatika kelas X/Fase E semester ganjil tahun pelajaran 2026–2027.

## Teknologi
- HTML
- CSS
- JavaScript murni (tanpa framework, database, atau login)

## Menjalankan di Windows
1. Ekstrak folder `misi-detektif-komputer`.
2. Buka folder tersebut di Visual Studio Code (File → Open Folder).
3. Buka `index.html` di browser (klik kanan → Open with Live Server jika ekstensi Live Server tersedia; atau buka file langsung dari File Explorer).
4. Tidak perlu menjalankan `npm install` atau perintah terminal.

## Isi prototype
- Beranda dengan gaya visual game edukasi biru-cyan-oranye.
- Materi: pengertian komputer, hardware, software, brainware, lima kelompok hardware, jenis software, serta alur input-proses-output-penyimpanan.
- Simulasi interaktif sederhana.
- Misi Detektif dengan enam fase PBL yang diselaraskan dengan LKPD.
- Evaluasi 10 soal pilihan ganda, skor otomatis, jawaban benar/salah, pembahasan, dan refleksi.

## Catatan
- Hasil evaluasi dan progres misi hanya berada di sesi browser; tidak ada akun atau database.
- Hasil penyelidikan kelompok tetap dicatat pada LKPD.
- Prototype ini adalah fondasi awal. Uji isi dan tampilan di laptop serta smartphone sebelum dipublikasikan.

## Publikasi ke GitHub Pages
1. Buat repository baru di GitHub.
2. Unggah seluruh isi folder ini ke root repository.
3. Buka Settings → Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch `main` dan folder `/ (root)`, lalu Save.
6. Tunggu proses deployment selesai dan buka alamat website yang diberikan GitHub Pages.
